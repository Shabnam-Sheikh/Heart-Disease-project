❤️ Heart Disease Data Analysis & Insight Generation

Heart disease remains one of the leading causes of death worldwide.
This project analyzes the Heart Disease UCI Dataset to identify patterns, risk factors, and relationships associated with heart disease occurrence.

Using Python, SQL, and data visualization techniques, the project explores how factors such as age, gender, cholesterol levels, chest pain type, blood pressure, and maximum heart rate contribute to heart disease risk.

The main goal is to generate meaningful healthcare insights that can support data-driven medical decision-making.

🎯 Objectives:
- Explore major risk factors linked to heart disease
- Analyze patient demographics and health indicators
- Identify patterns across age groups and gender
- Generate insights using statistical and SQL analysis
- Visualize relationships between medical attributes


📂 Dataset Information:
- Age
- Gender
- Chest pain type
- Cholesterol level
- Resting blood pressure
- Maximum heart rate achieved
- Fasting blood sugar
- ECG results
- Exercise-induced angina
- Heart disease diagnosis
